# SafeShutdown

一个基于 .NET 8 / WPF 的 Windows 断电保护工具。它通过持续 Ping 一个由市电供电的设备判断供电状态；连续失败达到阈值后，按配置顺序通过 SSH 向服务器发送关机命令，最后可选关闭本机。

## 主要功能

- 可配置监控间隔、Ping 超时和连续失败阈值，减少网络抖动导致的误判。
- 自动检测断电、手动关机、SSH 连接测试、主机排序与逐台延时关机。
- 断电缓冲期内允许取消；若缓冲期结束时监控设备恢复，会自动终止关机并恢复监控。
- 每台主机可单独启用、配置 SSH 端口以及选择是否通过 `sudo` 执行。
- 远程主机处理完成后，可选择是否关闭本机，并设置本机关机延时。
- 运行日志同时显示在界面中，并保留最近 30 天的日志文件。
- 配置原子写入；损坏的配置会备份，不会被默认值直接覆盖。
- SSH 密码在保存时使用 Windows DPAPI（当前用户范围）加密；旧版明文配置会在下次保存时自动迁移。
- 单实例运行，避免多个进程重复触发关机命令。

## 使用方式

1. 将“监控 IP / 主机名”设置为一个只在市电正常时在线的设备，例如路由器或智能插座。
2. 在主机列表中填写 SSH 地址、端口、用户名、密码、关机命令和前置延时。
3. Linux 主机通常保留 `sudo`；如果目标账户不需要提权，或目标不是类 Unix 系统，可取消勾选。
4. 先“测试 SSH”，确认所有主机可连接，再保存配置并开始监控。
5. 建议先关闭“远程主机完成后关闭本机”，完整演练一次流程后再启用本机关机。

主机的“延时”按列表顺序累计执行。例如三台主机分别设置 0、60、120 秒，第三台会在前两台处理完成后再等待 120 秒。

## 配置与日志

- 配置：程序目录下 `config/Config.json`
- 日志：`%LOCALAPPDATA%/SafeShutdown/Logs`

DPAPI 密文只能由保存它的 Windows 用户在同一系统中解密。复制配置到另一台机器或换用另一个 Windows 用户后，需要重新输入 SSH 密码。

## 安全建议

- 为 SafeShutdown 创建权限最小化的专用 SSH 用户，只允许执行所需的关机命令。
- 不要使用示例地址直接开始监控；新建配置默认不会自动启动监控。
- 监控目标应稳定且拓扑明确。若普通局域网故障也会让目标不可达，请适当提高失败阈值和断电缓冲时间。
- 当前版本仍依赖 SSH.NET 的默认主机密钥信任行为；请仅在受信网络中使用，并优先通过网络隔离与专用账户降低风险。

## 构建

```powershell
dotnet build SafeShutdown.sln
```

需要 Windows 和 .NET 8 Desktop Runtime。
